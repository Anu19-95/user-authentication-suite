# AuthSuite

An enterprise authentication suite with sign-in, account registration, password recovery, magic links, two-factor authentication, session management, role-based access control, and security audit logs.

## Run Locally

**Prerequisites:** Node.js


1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env.local` and configure any required environment values.
3. Run the app: `npm run dev`
